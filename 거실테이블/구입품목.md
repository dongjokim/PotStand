# 구입 품목

판이 없으면 Tokmanni 의 같은 치수 (EAN 6430019875018). Ø33·Ø35 봉과 철물은 사지 않는다.

## 도구 (이미 있으면 사지 않음)

- 톱. 판의 직선, 덧판, 봉의 직각 절단
- 곧은 자 또는 1m 가이드. 대각선이 휘지 않게
- 드릴, Ø8 비트. 테이프는 비트 끝에서 **21mm** (양쪽 공통)
- 클램프는 없어도 된다. 무거운 책·물통으로 눌러 말린다

## 사지 않는 것

- 철제 고정판, ㄱ자 철물, 나사
- 60×100이 있을 때의 60×200, 두 번째 봉
- Ø33·Ø35 봉
- 화분대용 선반핀
- 본드 300ml, Ø45 홀쏘
- P80 사포. 면이 패인다
